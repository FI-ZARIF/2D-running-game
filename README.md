This is a simple 2D Running Game developed using Java Swing.  
In this game, the player controls a character that runs continuously on the screen.  
Obstacles appear randomly and the player must avoid them.  
If the character collides with an obstacle, the game ends.  
The score increases as the player survives longer.  
The game includes restart and exit options.  
This project demonstrates basic game development using Java Swing and OOP concepts.
